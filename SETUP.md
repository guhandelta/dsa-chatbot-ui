# DSA Mentor — Local Setup

Two projects: `dsa-chatbot-api` (FastAPI backend) and `dsa-chatbot-ui`
(React/Vite frontend). Run the backend first.

---

## 0. Before anything: rotate your API keys

The original upload contained a committed `.env` with live OpenAI, Anthropic,
and Google keys. Revoke and regenerate all three. If that `.env` was ever
committed, the keys are still in your Git history even after deleting the file
— rotating is the only real fix. See "Purging secrets from history" at the
bottom if you also want them out of the history.

---

## 1. Prerequisites

| Tool | Needed for | Check |
|---|---|---|
| Python 3.11+ | backend | `python3 --version` |
| Node 20+ | frontend | `node --version` |
| gcc / g++ | verifying C and C++ solutions | `gcc --version` |
| javac | verifying Java solutions (optional) | `javac --version` |
| rustc | verifying Rust solutions (optional) | `rustc --version` |

On macOS, gcc/g++ come with Xcode command line tools (`xcode-select --install`).
For the optional two:

```bash
brew install openjdk rust
```

Without them, Java and Rust submissions are marked **unverified** rather than
passing — the app works, it just can't execute those two languages.

## 2. Backend

```bash
cd dsa-chatbot-api

python3 -m venv venv
source venv/bin/activate            # Windows: venv\Scripts\activate

pip install -r requirements.txt -r requirements-dev.txt

cp .env.example .env
```

Edit `.env`:

```bash
OPENAI_API_KEY=sk-...               # your NEW key
ANTHROPIC_API_KEY=sk-ant-...        # optional
GOOGLE_API_KEY=...                  # optional

JWT_SECRET=<paste output of the command below>
ADMIN_EMAILS=you@example.com        # makes this account an admin on signup
```

Generate a real secret:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

Run the tests (no API key or network needed — the LLM layer is mocked):

```bash
pytest
```

Seed the vector store from the markdown content (needs your OpenAI key —
this call costs a few cents in embeddings):

```bash
python -m app.services.knowledge_base
```

Start it:

```bash
uvicorn app.main:app --reload --port 8000
```

API docs at http://localhost:8000/docs

### Offline verification (no dependencies required)

```bash
python tools/check_snippets.py            # compile every solution snippet
python tools/check_python_correctness.py  # run Python refs against known I/O
python tools/brute_force_check.py         # catalog + sandbox stress tests
```

## 3. Frontend

New terminal:

```bash
cd dsa-chatbot-ui

cp .env.example .env                # VITE_API_URL=http://localhost:8000
npm install
npm test                            # vitest
npm run dev                         # http://localhost:3000
```

## 4. First run

1. Open http://localhost:3000 and register with the email you put in
   `ADMIN_EMAILS` — you'll be an admin with 50 peppercorns.
2. **Learn & Practice** → pick your language, then a track.
3. **Train** (admins/teachers) → submit a problem; it's reviewed, completed in
   all six languages, executed, and published only if everything passes.
4. **Admin** → promote other accounts to `teacher`.

## 5. Troubleshooting

**`no such column: users.role` or `users.preferred_language`**
The schema changed and there are no migrations yet. Delete the dev database and
re-register:

```bash
rm dsa-chatbot-api/dsa_chatbot.db
```

**Frontend can't reach the API**
Check the backend is on port 8000 and `CORS_ORIGINS` in the backend `.env`
includes `http://localhost:3000`.

**`routeTree.gen.ts` missing**
It's generated by the TanStack router plugin on the first `npm run dev`. Run
the dev server once before `npm run build`.

**Training says a language is "unverified"**
That toolchain isn't installed. See Prerequisites.

**Chroma returns nothing / empty answers**
You haven't seeded: `python -m app.services.knowledge_base`.

## 6. Purging secrets from history (optional)

Rotating keys is mandatory; this is only if you also want them out of the
repo history. It rewrites history, so coordinate with anyone else on the repo.

```bash
# from the repo root, with a clean working tree
pip install git-filter-repo
git filter-repo --path .env --invert-paths
git push --force origin main
```
